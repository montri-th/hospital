# กราฟเปรียบเทียบพื้นที่

ถาดกราฟด้านล่างแผนที่ (“เปรียบเทียบพื้นที่”) มีสามมุมมอง ใช้ข้อมูลชุดเดียวกับข้อค้นพบแรกและ choropleth คือ **scopeRows** (แถวตามตัวกรองค้นหา/ประเภท/ขนาด/จังหวัด/สังกัด ก่อนเลือกพื้นที่) และมาตรวัดเดียวกับแผนที่ (เตียง หรือ สถานพยาบาล) แท่งและช่องเป็นปุ่ม: ของเขต/อำเภอเปิดพื้นที่นั้น ของสังกัดตั้งตัวกรองสังกัดและเปิดบัตรสังกัด กราฟวาดด้วย HTML ของเดโมเอง ไม่ใช้ไลบรารีกราฟ (`js/charts.js`, `js/chart-model.js`)

| มุมมอง (`?view=`) | คำถาม | การเข้ารหัส | ตัวชี้วัด | ขอบเขต |
|---|---|---|---|---|
| เขต/อำเภอ (`areas`, ค่าเริ่มต้น) | เขต/อำเภอไหนมีเตียง (หรือสถานพยาบาล) มากที่สุด | แท่งแนวนอนเรียงลำดับ สีระดับเดียวกับแผนที่ (`li.supply` หรือ `count`) ตัวเลขอยู่นอกแท่ง ใต้ชื่อบอกจังหวัดและอีกมาตรวัดหนึ่ง | เตียง หรือ แห่ง | 20 เขต/อำเภอแรก |
| ประเภท (`mix`) | เขตที่มีมากเป็นสถานพยาบาลประเภทใด | matrix เขต × 8 ประเภท ทุกช่องขนาดเท่ากัน สีช่อง = 41 ระดับตามลำดับค่าของช่องในตาราง หัวคอลัมน์มีรูปทรงของประเภท ช่องที่ทุกแห่งไม่ทราบเตียงเป็นขีด | เตียง หรือ แห่ง ต่อช่อง | 12 เขต/อำเภอแรก |
| สังกัด (`aff`) | สังกัดใดมีเตียง (หรือสถานพยาบาล) มากที่สุดในตัวกรองนี้ | แท่งแนวนอนสีพื้นฐานกลางเดียว (สังกัดไม่ใช่หมวดของแผนที่) ใต้ชื่อบอกอีกมาตรวัดหนึ่ง | เตียง หรือ แห่ง | ทุกสังกัดที่พบ |

## ความหมายของการเข้ารหัส

- **ความยาวแท่ง** เทียบกับค่าสูงสุดในกราฟ ตัวเลขจริงอยู่ข้างแท่งเสมอ ค่าเท่ากันเรียงตามอีกมาตรวัดหนึ่งแล้วตามชื่อ
- **Matrix ช่องเท่ากันทุกช่อง** ขนาดช่องไม่มีความหมาย ช่อง 0 คือ measured zero (ระดับ 0 + เส้นขอบศูนย์) ไม่ใช่ช่องว่าง
- **เตียงที่ไม่ทราบ** ไม่ถูกนับเป็น 0 เตียงในแท่งหรือช่องใด; 0 ที่ทะเบียนรายงานคือ 0

## สีและระดับ

- เตียงต่อพื้นที่: `li.supply` (Location Intelligence Profile, scaleVersion `671112f3…c497`) · สถานพยาบาลต่อพื้นที่: `count` (`4ff5c1fb…0980`) — ยอดรวม ไม่ใช่ความหนาแน่นหรืออัตราต่อประชากร · ครบ 41 ระดับตามลำดับค่า (`js/scales.js#buildRamp`) สีเดียวกันทั้งสองธีม
- ประเภทสถานพยาบาล: categorical `landometer-series-10-v8` ผูกด้วย id พร้อมรูปทรงประจำ series ไม่ใช้ดาว
