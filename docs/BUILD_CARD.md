## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** เตียงที่ทะเบียนรายงานกระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด ใกล้สถานีรถไฟฟ้าที่เปิดแล้วแค่ไหนเมื่อเทียบกับเขตอื่น และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีตตรวจถึง 1 พ.ย. 2569, รุ่น 0.1.0): **“32% ของเตียงในกรุงเทพมหานคร อยู่ใน 3 เขตนี้”** ราชเทวี · บางกอกน้อย · ปทุมวัน — 10,984 จาก 34,030 เตียง · แท่ง “ใกล้รถไฟฟ้า ≤ 500 ม.”: 3 เขตนี้ 38% (4,198/10,983) · เขตอื่น 37% (8,285/22,430) ฐานอยู่ในคำอธิบายของแท่ง · ข้อค้นพบรอง “อันดับ 1 นอกกรุงเทพมหานคร: อำเภอเมืองเชียงใหม่ เชียงใหม่ 4,113 เตียง” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 เขตนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth `li.supply` สัญลักษณ์สถานพยาบาลตามประเภท (ขนาดตามจำนวนเตียง เฉพาะแถวที่มีหมุด) สถานีรถไฟฟ้าเป็นวงกลมเงียบ และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกพื้นที่” (`?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) · สลับ “เตียง | สถานพยาบาล” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “9% ของสถานพยาบาลในกรุงเทพมหานคร อยู่ใน 2 เขตนี้” (บางกะปิ · จตุจักร — เขตที่สามเท่ากับเขตถัดไป จึงไม่ตัดผ่าน) และข้อค้นพบรอง “อำเภอหาดใหญ่ 460 แห่ง · มากกว่าทุกเขตของกรุงเทพมหานคร”

## Evidence cue and calculation

แหล่ง: `data/hospitals.json` (41,828 แถว; 186,453 เตียงจาก 1,597 แห่งที่มีเตียง) และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| เขต | รหัส | เตียง | แห่ง |
|---|---|---:|---:|
| ราชเทวี | `1037` | 5,891 | 80 |
| บางกอกน้อย | `1020` | 2,863 | 76 |
| ปทุมวัน | `1007` | 2,230 | 87 |

จังหวัดที่นำ = จังหวัดที่มีเตียงที่ระบุเขต/อำเภอได้มากที่สุด (กรุงเทพมหานคร 34,030 เตียง) สัดส่วน = 10,984 ÷ 34,030 = 32% ตัวหารคือเตียงทั้งจังหวัดในตัวกรอง สถานพยาบาลที่ไม่ทราบจำนวนเตียงไม่อยู่ในทั้งตัวตั้งและตัวหาร (จำนวนอยู่ในคำอธิบายของตัวเลข “เตียง”) สัดส่วนใกล้รถไฟฟ้านับเฉพาะเตียงของสถานพยาบาลที่มีหมุด ฐานทั้งสองฝั่งอยู่ในคำอธิบายของแท่ง

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกเขต:** ถ้าเขตลำดับถัดไปมีค่าเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า ถ้าทุกเขตเท่ากันข้อค้นพบเปลี่ยนเป็น “กระจาย” จังหวัดที่มีเขตที่มีค่าไม่เกิน 3 เขตโฟกัสเฉพาะ N − 1 เขตบนสุด

## States

| State | ผลบนหน้าจอ |
|---|---|
| โหลด | การ์ดเปิดเว็บ (`js/shell/launch.js`) จนข้อมูลพร้อม |
| ไม่พบตามตัวกรอง | “ไม่พบสถานพยาบาลตามตัวกรองนี้” + ล้างตัวกรอง |
| ตัวกรองที่ไม่มีเตียง (รพ.สต. คลินิก) | “N แห่ง · ไม่มีเตียงตามทะเบียน” + “นับเป็นแห่ง” · “ดูรายชื่อ” |
| เขตที่ไม่มีสถานพยาบาลตามตัวกรอง | measured zero ของชุดข้อมูลนี้ + “ดูพื้นที่ที่พบ” |
| ไม่ทราบจำนวนเตียง | นับเป็นแห่ง ไม่นับเป็น 0 เตียง; เขตที่ไม่ทราบทั้งหมดเป็นลายทแยง (no data) |
| ไม่มีหมุด (แถว HCODE) | นับในเขต/อำเภอและรายชื่อ ชิป “ไม่มีหมุด” ไม่มีคู่เทียบ แผนที่จัดภาพเขตของแถว |
| แผนที่โหลดไม่ได้ | ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ พร้อมปุ่มลองใหม่ |
| ขอบเขตจังหวัดโหลดไม่ได้ | รายงานและลองใหม่เมื่อขอครั้งถัดไป แผงไม่พึ่งขอบเขต |
| เลือกสถานพยาบาลที่มีหมุด | แผนที่เปลี่ยนเป็น 3 มิติ กล้อง 2-point ที่อาคารที่หมุดอยู่ในขอบ (“อาคารของสถานพยาบาล”) |
| หมุดไม่อยู่ในขอบอาคาร | กล้อง 2-point ที่อาคารใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็โหลดถึง 800 ม.) หมุดอยู่ในภาพ ป้าย “อาคารใกล้หมุด” — ไม่นับใน “สถานพยาบาลในอาคารนี้” |
| ไม่มีอาคารบนแผนที่ในระยะ 800 ม. | กล้อง 2-point ที่พื้นที่รอบหมุด (กล่อง 90 ม.) |
