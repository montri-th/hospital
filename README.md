# CityMETER: Hospital

**เตียงสถานพยาบาลกระจุกอยู่ตรงไหน และใกล้รถไฟฟ้าแค่ไหน** — เดโมแผนที่ 3 มิติของโรงพยาบาลและหน่วยบริการสุขภาพทั่วประเทศไทย ที่อ่านเตียงตามทะเบียนเป็นยอดต่อเขต/อำเภอ พร้อมระยะถึงสถานีรถไฟฟ้า สังกัด ระดับ มาตรฐาน HA/JCI ที่เผยแพร่ ราคาแล็บของ DIT บริการ คู่เทียบขนาดใกล้กัน และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/hospital/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=hospital
- รุ่น 0.1.0 · 5 พฤศจิกายน 2569 · ชีตวิจัยตรวจแหล่งถึง 1 พฤศจิกายน 2569 (อ่าน 5 พ.ย.) · หมุดและขอบเขต production อ่าน 5 พฤศจิกายน 2569

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **32% ของเตียงในกรุงเทพมหานคร (10,984 จาก 34,030 เตียง) อยู่ใน 3 เขต — ราชเทวี บางกอกน้อย ปทุมวัน** · ใกล้รถไฟฟ้า ≤ 500 ม.: 3 เขตนี้ 38% (4,198/10,983 เตียง) เขตอื่น 37% (8,285/22,430) · อันดับ 1 นอกกรุงเทพฯ คือเมืองเชียงใหม่ 4,113 เตียง

> ชุดข้อมูล CityMETER Hospital จาก CityMETER Hospital · ทะเบียน HCODE · ตรวจ 1 พ.ย. 2569 · ขอบเขต เขต/อำเภอของ CityMETER ทั่วประเทศ · วิธีนับ: `DATA_METHOD.md`

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** โฟกัสเขต/อำเภอที่มีเตียงมากที่สุด (ไม่เกิน 3) ของจังหวัดที่มีเตียงระดับเขตมากที่สุด บอกสัดส่วน ตัวตั้ง ตัวหาร สัดส่วนใกล้รถไฟฟ้าเทียบส่วนอื่นของจังหวัด และพื้นที่ที่มากที่สุดนอกจังหวัด — ไม่ตัดผ่านค่าที่เท่ากัน และไม่โฟกัสทุกเขตของจังหวัด
- **เตียง | สถานพยาบาล:** สลับมาตรวัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเปลี่ยนพร้อมกัน (สเกล `li.supply` สำหรับเตียง และ `count` สำหรับแห่ง ครบ 41 ระดับของ LDS) กลุ่มที่ทะเบียนไม่มีเตียง (รพ.สต. คลินิก) เสนอให้นับเป็นแห่งในคลิกเดียว
- **สถานีรถไฟฟ้า (CityMETER Transit):** วงกลมเล็กบนแผนที่ กดเพื่อดูสถานพยาบาลในรัศมีระยะตรง 500 ม. พร้อมวงรัศมี และลิงก์ไปสถานีเดียวกันใน CityMETER Transit
- **ขนาดสัญลักษณ์ตามจำนวนเตียง:** พื้นที่ของสัญลักษณ์เพิ่มตามเตียงตามทะเบียน สีและรูปทรงบอกประเภท (8 ประเภท) วงโปร่ง = ไม่ทราบจำนวนเตียง
- **ชื่อกลางจอ:** ตั้งแต่ระดับไซต์ ชื่อสั้น (รพ. · รพ.สต. · ศบส.) ของสถานพยาบาลที่มีเตียงมากและมีมาตรฐานที่เผยแพร่ก่อน ไม่เกิน 9 ป้าย (มือถือ 5) ชี้แล้วเห็นการ์ดไอคอน: ประเภท เตียง สังกัด ระดับ มาตรฐาน
- **สถานพยาบาลหนึ่งแห่ง:** กดที่มีหมุด แผนที่เปลี่ยนเป็น 3 มิติและเปิดมุมมองอาคาร 2-point perspective — อาคารที่หมุดอยู่ในขอบ หรืออาคารที่ใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็ขยายเป็น 800 ม.) · เตียงและขนาด สังกัด ระดับ HA (ถึงวันที่) JCI บทบาทในเครือข่าย สปสช. สถานีที่ใกล้ที่สุด · **ราคาแล็บ 6 รายการ** (DIT) พร้อมระดับเทียบ 262 แห่งที่มีครบ · **บริการ** ที่ผู้ให้บริการและทะเบียนระบุ · **คู่เทียบ** (ประเภทเดียวกัน · เตียง ½–2 เท่า · ≤ 5 กม.)
- **สังกัด:** กรองตามสังกัด (กระทรวงสาธารณสุข · ท้องถิ่นและกรุงเทพมหานคร · หน่วยงานรัฐอื่น · เอกชน) เพื่อดูเตียง แห่ง จังหวัด และสัดส่วนใกล้รถไฟฟ้า
- **อาคารรายพื้นที่:** แต่ละ อปท. (กรุงเทพฯ รายเขต) ใช้อาคาร CityMETER Building V4 เมื่อมีอาคารมากกว่า OpenStreetMap ตั้งแต่ 15% ขึ้นไป ไม่เช่นนั้นใช้ OSM ความสูงของ CityMETER เป็นค่าประมาณ (หน่วยอาคารชุดเดียวกับ CityMETER · Hotel 0.3.6) ในพื้นที่ที่มีเนินเขา อาคารตั้งบนพื้นดิน 3 มิติ
- **ภาษา:** สั้น ใช้ไอคอนและกราฟแท่งเล็กแทนประโยค ไม่มีคำเตือนบนหน้าจอ ทุกแผงจบด้วยบรรทัดที่มาและลิงก์ “วิธีนับ”
- **มือถือ:** ข้อค้นพบกับคำอธิบายแผนที่รวมเป็นแถบเดียวด้านล่าง แผงข้อมูลเปิดตรงสิ่งที่เลือก
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู (เวลาเปิด แพทย์เฉพาะทาง สิทธิการรักษา การเดินทาง) พร้อม Google Maps และ Street View เมื่อมีหมุด · คำตอบของ Google ไม่ถูกนำมาเป็นข้อมูลในหน้านี้
- **เส้นทาง:** ประเทศไทย › จังหวัด › เขต/อำเภอ ใช้รหัสเดียวกับ CityMETER production และเปิดพื้นที่เดียวกันในระบบจริงได้ (`?d=hospital`)
- **ลิงก์ตรง:** `?metric=count` · `?area=1037` · `?areas=1037,1020,1007` · `?areas=all` · `?province=CMI` · `?group=private` · `?size=b5` · `?aff=moph` · `?facility=CMH-11699` · `?station=<id>` · `?view=aff` · `?view3d=0`

## ข้อมูล

- `data/hospitals.json` — 41,828 รายการจากชีตวิจัย (12,516 จาก CityMETER production พร้อมหมุด + 29,312 จากทะเบียน HCODE) ไม่เผยแพร่ชีตหรือแท็บที่อ่าน — `scripts/build-data.py`
- `data/area-index.json`, `data/frames/{CODE}.json`, `data/provinces.geojson` — เขต/อำเภอและจังหวัดของ CityMETER production — `scripts/build-boundaries.py`
- `data/boundary-receipts.json` — ใบรับของทุก response จาก production base info
- `data/building-units/` — แหล่งอาคารราย อปท./เขต ตามเกณฑ์ 15% (ชุดของ CityMETER · Hotel 0.3.6)
- วิธีทั้งหมด ข้อจำกัด และงานวิจัยที่ต้องตามต่อ: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `llms.txt`
