# CityMETER Hospital — owner preferences

Set 2026-11-05 (release 0.1.0) on the owner request “จากที่เราทำ demo ของ CityMETER: Hotel มาแล้ว ใน montri-th.github.io/hotel ขอให้ทำแบบเดียวกันให้กับ CityMETER: Hospital แล้ว publish ที่ github.com/montri-th/hospital โดยใช้ข้อมูลจาก [the hospital research master] ซึ่งรวบรวมมาจาก งานเดิมใน production ที่เป็น CityMETER: Hospital มาปรับปรุง ตาม source ของ landometer.com/v3/citymeter?d=hospital และ landometer.com/citymeter/healthcare … update registry sheet ด้วย”. Code base: montri-th/hotel @177e592 (release 0.3.6); every standing rule of CityMETER · Hotel carries over unless this file says otherwise. The registry row `research.TH.hospital` (R01_DATASETS, demo columns V:Y) and a `Changes` row record the release.

- Apply current LDS 0.9.7 (v0.9.7-owner.1, standalone-0.9.7-r1, color-srgb-10) and the Location Intelligence Profile for LDS 0.9.7 (`li.supply` for beds), and preserve the map-first CityMETER layout. Colours come only from `assets/theme.css`, `js/scales.js` and `js/cues.js`; never approximate a value by eye. Owner standing rule: “Color scale ขอให้ใช้ 41 scales ตาม LDS เสมอ”. `npm run check:lds -- --lds <base> --li <profile>` compares every shipped value with both source files.
- Read `PRODUCT_STATEMENT.md` before changing what the first screen argues. The question is “เตียงสถานพยาบาลกระจุกอยู่ตรงไหน และใกล้รถไฟฟ้าแค่ไหน”.
- Measure is a contract (`js/model.js#METRICS`, `rowValue`): beds the HCODE register reports (Σ `official_reported_beds_text`, “เตียง”, `li.supply`) by default, records (“แห่ง”, `count`) on the switch; the map, legend, labels, Aha, ranks and charts read the same measure. A reported 0 is a 0 (“ไม่มีเตียง”); unknown beds are never 0: counted apart (“ไม่ทราบจำนวนเตียง”, a hatched swatch), a district whose records all have unknown beds is `no_data`. A selection without beds (primary care, clinics) offers the record measure (“นับเป็นแห่ง”) instead of an empty Aha. Never call a figure staffed beds, occupancy, demand, patient volume, revenue, a market share, a density or beds per person.
- Quality, prices and services are per facility and as published: HA stage with its dates, JCI programmes, the DIT six-item lab basket (with its quintile level among the 262 facilities that list all six; “ราคาแล็บ 6 รายการ”, effective date a field of the closed source details), services as the sheet records them. Never a ranking of quality or outcomes, never summed or averaged across facilities, never a bill or a package. A missing chip is not a failed accreditation or a missing service (it stays off screen; `DATA_METHOD.md` says so behind “วิธีนับ”).
- Aha first, in 3D: the first paint is the `city` preset framing up to three เขต/อำเภอ with the most of the measure in the province that holds the most of it at district level, focused automatically. Show the share (Σ focus ÷ the province's whole total in the selection: “32% ของเตียงในกรุงเทพมหานคร อยู่ใน 3 เขตนี้”), numerator and denominator, the rail comparison as two bars (both bases in each bar's title and accessible text; hidden when nothing is near an operating station) and the district(s) with the most outside that province. Never cut through a tie, never focus every district that holds the measure (`js/area-insight.js`). Snapshot numbers in the handoff JSON are fixtures, never UI constants.
- Membership is the district matched at build time from the row's own registered district (`row.admin`: name · code · point · province · conflict · none). Never re-assign by point-in-polygon on display coordinates. A production point in another district stays a point; the disagreement is reported (`meta.checks`), not fixed in `data/`.
- Points are production's own (`layer-hospital-detail`). HCODE records carry none and are never given one by geocoding a name or an address; they count in their district and lists. Counts round a point (station radius, “สถานพยาบาลบนแผนที่รอบ 5 กม.”) say they are of facilities on the map.
- Names: the sheet's name, except a private hospital's licence class appended by the licence register, which reads under the heading as “ชื่อตามทะเบียน” (`scripts/build-data.py#display_name`). Never rename by hand in `data/`; change the sheet, then rebuild. Brand/service families (`01_BRANDS`) are not linked to facilities: never infer a family from a name; the affiliation filter (`aff`) stands in for the chain filter of Hotel.
- Context comes from datasets of the same registry, joined by id with the commit and SHA-256 recorded (`meta.context`): CityMETER · Transit stations (operating drawn as quiet clickable rings; under construction named in words only, “กำลังสร้าง”). Every distance is a straight line between reference points — the distance pictogram, “ระยะตรง” in titles — never a walking route, a travel time or a catchment. The NHSO role is production's grouping in production's own words.
- Comparison set (`js/profile-model.js#compsetOf`): same facility group, beds ½–2× the facility's own within 5 km straight line (a facility without beds: same group within 2 km), nearest first, every row of the dataset; headed “คู่เทียบ” with the rule as chips; never “คู่แข่ง” or a referral network.
- National scale: `data/area-index.json` has every district without geometry; outlines load per province (`js/frames.js`). Never load all 77 frame files up front.
- Focus + quiet context: detail only for the focused part; everything else visible but quiet. Below zoom 8 the province frames carry the reading — except with a จังหวัด filter.
- Facility groups bind by stable id to LDS series with the series shape cue (`js/cues.js#GROUP_SERIES`: regional 1 · private 2 · community 3 · public_other 4 · center 7 · clinic 8 · other 9 · subdistrict 10). Never colour a category by hue alone; no star cue. Symbol size: area ∝ reported beds (`js/model.js#pinRadius`, floor 3 px for a reported 0), unknown beds hollow at the 10-bed size; larger symbols drawn first. One symbol = one row with a point; never cluster or aggregate.
- Names near the middle of the view (`js/labels.js`): from zoom 12.5, focus rows ranked by `row.importance` (beds percentile + published accreditation + beds > 0; ranking only, never shown), at most 9 on desktop and 5 on a phone; short names (รพ. · รพ.สต. · ศบส. · ศสม.), the full name stays the accessible name; hover/focus card of icon chips (type, beds, affiliation, level, accreditation); no caveats in the card.
- Building view (Hotel 0.3.2 rule, owner 2026-11-02 “… ต้องแสดง 2-point perspective ของ 3d building mass ทุกกรณี”): choosing a facility with a point switches the map to 3D and opens the two-point camera on the drawn building holding the pin, else the nearest drawn building within 300 m (800 m when none), framed with the pin and labelled “อาคารใกล้หมุด” — a camera choice, never a join or a located-in claim. Follow the camera, x-ray and MapLibre 5.6.2 guard contracts of `js/shell/camera.js`, `js/massing.js`, `js/shell/venue-xray.js`, `js/shell/maplibre-guard.js`; do not reorder the massing, x-ray, station and pin layers casually.
- Buildings per area (`data/building-units/`): the units of CityMETER · Hotel 0.3.6 (อปท./เขต holding a hotel). Rebuilding them round the facility points is the next data step (`scripts/build-building-units.py`); the 15 % rule does not change.
- Map text is icon-first; pictograms come from the approved subset (`scripts/build-pictogram-font.py`: + hospital, service, accredit, lab, network, level, affiliation in 0.1.0). Icon-only controls only where the symbol is conventional.
- Outbound actions (`js/ask.js`): ถาม Google AI as a plain Google Search with the question of the view (never `udm=50`, Hotel 0.3.3), Google Maps, Street View only with a point. Public names and published points only. Nothing from Google's answers enters the data.
- Phone layout (Hotel 0.3.5): below 761 px in portrait the Aha and the legend share one dock; touch phones hide the zoom buttons; the sheet opens on the selection.
- Breadcrumb ประเทศไทย › จังหวัด › เขต/อำเภอ with production codes and deep links `/v3/citymeter/{code}/D/{district}?d=hospital`. A facility or a station is the panel heading, never a crumb.
- Every panel view ends with exactly one provenance line (`provenance()` in `js/panel.js`): dataset · source · date · boundary, then “วิธีนับ” (`DATA_METHOD.md`). No caveat anywhere on screen (owner rule carried over from Hotel 0.3.1: “เรื่องภาษา ขอที่ กระชับอ่านเข้าใจง่าย ใช้ symbol, logo, icon, charts มาช่วยทำให้ text กระชับ … ไม่มี caveats เลย และเป็นธรรมชาติ”); exactness comes from the names, the numerator and denominator of every share and the provenance line (`tests/views.test.js`).
- Copy: short, natural Thai in the ICP's words (เตียง แห่ง ประเภท สังกัด ระดับ มาตรฐาน ราคาแล็บ บริการ คู่เทียบ ใกล้รถไฟฟ้า อันดับ); units on every number; a number and its unit never split across lines. No static counts in page copy.
- Privacy and publication: never copy addresses, licence codes, phone numbers, operator groups, researcher notes, review or data-gap codes, raw source records (`meta.excludedFields`). Never commit the internal research sheet or its tabs as read, private Drive/Sheet URLs, credentials, the full LDS library or the Location Intelligence Profile. Never put Landometer prices, contracts, proposals or pipeline in this repository. Never put a personal email in a User-Agent (`CityMETER-Hospital-build/1.0`).
- Review Thai at desktop and 390 px in light and dark before claiming done; local renders are not proof of a live release — run `npm run verify:live` and walk the live site.
- Releases bump one cache tag `?v=YYYYMMDD-rN` on every entry in `index.html` and, through the import map, on every ES module, together with `package.json` version, `design-intent.json` and the handoff JSON `productVersion` (`tests/release.test.js`). A new module must be added to the import map. Icon fonts inside the stylesheets carry `?v=<first 8 hex of their SHA-256>` (`tests/icons.test.js`).

## Discovery and dataset group (owner decision 2026-11-08)

- Every page carries `<meta name="robots" content="noindex, nofollow">`. The owner does not want search engines to index the demos while developers keep building on them: “ไม่ต้องการให้เสิช engine เข้ามาดูเดโม แต่อยากให้ dev นำ demo บน github ไป vibe coding ต่อได้ง่าย คือ SEO อันไหนจัดการได้จัดการไปเลย แต่ยังไม่ต้องให้ crawler เข้ามา index”. Keep the rest of the SEO metadata ready for production, do not block crawlers in a robots.txt (they must be able to read the noindex), add no sitemap, and never point `rel="canonical"` at landometer.com from a noindex page. `tests/discovery-and-group.test.js` guards this.
- The panel eyebrow `CITYMETER · LOCATION` follows the dataset registry (`R01_DATASETS.dataset_group`; owner: “ใช้ตามทะเบียนทั้งหมด”). This dataset is LOCATION in the registry read on 2026-11-08; change the label only when the registry changes.
